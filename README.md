## 📋 Lista de Tareas

Mi primer proyecto completo: una lista de tareas interactiva.

**🔗 [Ver la página en vivo](https://jabo6311.github.io/mis-proyectos-web/lista-de-tareas.html)**

### Funcionalidades

- ✅ Agregar tareas nuevas (con botón o presionando Enter)
- ✅ Marcar tareas como completadas con un clic
- ✅ Eliminar tareas
- ✅ Validación para evitar tareas duplicadas
- ✅ Niveles de prioridad (Alta / Media / Baja) con colores
- ✅ Contador de tareas pendientes
- ✅ Las tareas se guardan automáticamente (localStorage), aunque recargues la página

### Tecnologías usadas

- HTML5
- CSS3
- JavaScript (vanilla, sin frameworks)
